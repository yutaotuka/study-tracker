同期設定（GitHub Gist）

非公開のGistに進捗を保存して、別の端末やブラウザから続きを使えるようにします。 以前のバージョンで接続済みなら、この設定は不要です（トークンとGist IDを引き継ぎます）。

  1. GitHubで Settings → Developer settings → Personal access tokens → Tokens (classic) を開く
  2. Generate new token (classic) を押し、スコープは gist だけにチェックを入れる
  3. 有効期限を設定して生成し、表示されたトークンをコピーする
  4. 下の欄に貼って「接続」を押す（初回はGistが自動で作られます）

既に接続済みの場合、進捗は同じGist内の study-progress-v2.json に保存されます。 以前の進捗ファイルは上書きされません。

トークンはこのブラウザ内にのみ保存され、GitHub以外には送信されません。 スコープを gist だけに絞り、有効期限を設定しておくと安全です。

サマリー 週別タスク手順 課題一覧 日次ログ ルール

進捗はこのブラウザの localStorage に保存されます。端末をまたいで使うには 「同期設定」からGistを接続するか、「書き出し」で保存したJSONを別の端末で「読み込み」してください。 JSONファイルはこの画面にドラッグ＆ドロップしても読み込めます。
